# Screenshots / スクリーンショット

This directory is reserved for release-ready screenshots referenced by the project README. No screenshots are currently published.

このディレクトリは、プロジェクトREADMEで使用する公開用スクリーンショットの保存先です。現在、公開済みのスクリーンショットはありません。

## Recommended files / 推奨ファイル名

```text
storefront-desktop.webp
product-detail.webp
cart-checkout.webp
account-mobile.webp
admin-dashboard.webp
```

Prefer WebP or optimized PNG files. Use descriptive lowercase names with hyphens and keep each image reasonably sized for GitHub rendering.

WebPまたは最適化したPNGを使用し、内容が分かる小文字のファイル名をハイフン区切りで付けてください。GitHubでの表示に適したファイルサイズに抑えます。

## Safety checklist / 安全確認

Before committing a screenshot, confirm that it contains none of the following:

- API keys, tokens, cookies, or environment variables
- Private URLs, database connection strings, or local absolute paths
- Real names, email addresses, postal addresses, or payment details
- Production customer, order, or analytics data
- Browser bookmarks, account avatars, notifications, or unrelated desktop content

コミット前に、APIキー、認証情報、非公開URL、ローカル絶対パス、個人情報、本番の顧客・注文・分析データ、ブラウザやデスクトップ上の無関係な情報が写っていないことを確認してください。
